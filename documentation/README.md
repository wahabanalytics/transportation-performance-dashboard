# Project Documentation

This folder contains the supporting documentation for the Transportation Performance Dashboard project.

## Documents

### Project Proposal

The project proposal defines the business problem, project objectives, analytical approach, dashboard requirements and expected outcomes.

**File:** `Project_Proposal.pdf`

### Final Project Report

The final project report documents the completed solution, methodology, dashboard architecture, analytical capabilities, key features and project outcomes.

**File:** `Project_Report.pdf`

### Project Summary

The project summary provides a concise overview of the project, including its purpose, tools, key features, business value and skills demonstrated.

**File:** `Project_Summary.pdf`
