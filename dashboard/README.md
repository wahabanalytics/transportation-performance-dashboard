# Dashboard

This folder contains the interactive Microsoft Excel Transportation Performance Dashboard.

## Main File

`Transportation_Performance_Dashboard.xlsm`

The workbook contains:

- Interactive PivotTables
- KPI cards
- Slicers
- Dynamic dashboard title
- Dynamic filter-context subtitle
- Month-over-Month performance indicators
- Business-context MoM colour logic
- Route, branch and driver analysis
- Revenue and cost analysis
- Passenger and trip analysis
- Vehicle occupancy analysis
- On-Time performance analysis
- VBA automation
